# ClassIQ – HTML/CSS/JS build

Open `index.html` in a browser. No build step, no libraries.

Pages: index.html (landing), login.html, signup.html, dashboard.html
Files: css/style.css, js/main.js, assets/logo.svg, assets/avatar.svg

To use your own images, replace assets/avatar.svg (or change the <img src>) and keep the file name/extension in sync.
Fonts (Poppins, Inter) load from Google Fonts; the page falls back to system fonts offline.
